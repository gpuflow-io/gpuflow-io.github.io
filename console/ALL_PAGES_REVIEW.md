# 전체 페이지 검수 결과

2026-11-10 · 기관 검토용 Draft. 실측 데이터 추가 수집·제품 인수 완료를 뜻하지 않습니다.

## 공통 수정

- 저장된 관측 모드에서 다른 페이지로 이동해도 시나리오가 자동으로 섞이지 않습니다. 시나리오는 명시적으로 전환합니다.
- 과거 관계는 관측 시각 기준으로 판정하고 현재 상태와 구분합니다. 원천의 stale/conflict 품질 검사도 유지합니다.
- 미계측, 표본 미포함, 미등록, 관측 만료를 구분하고 필요한 데이터와 결정 사항을 표시합니다.
- 기존 20개 위젯 검토 연결을 관측 모드에서도 유지합니다. 브라우저 회의 기록의 저장 버전은 유지합니다.
- 시나리오의 LIVE 표기를 SCENARIO로 정정하고, KPI 예시 값에 목표 달성 판정을 하지 않습니다.

## 관측 범위

제공 표본은 식별자를 치환한 과거 실측 자료입니다. 등록 GPU 1개, 컴퓨트 노드 1개, 스토리지 노드 2개, Pool 1개, Container 1개, 등록 rank 레코드 2개와 종료된 benchmark 작업 3건을 포함합니다. 전체 클러스터의 현재·원자적 스냅샷이 아니며 GPU 시계열은 포함하지 않습니다.

스토리지 요약은 선택 클러스터의 표본 전체이며 컴퓨트 POD/랙/노드 필터를 적용하지 않습니다. 컴퓨트 필터 적용 범위는 각 화면에 명시합니다.

## 검증 방법

- Node 판정·샘플 회귀 83개.
- 13개 화면의 관측/시나리오 모드, 데스크톱/모바일 순회와 가로 넘침 검사.
- 20개 기존 위젯의 관측 모드 검토 연결, 필터·상세·경로·비교 이동, 오프라인 오류 및 제품 API 호출 부재 확인.
- 기존 검토 모드의 기록 보존·내보내기·입력 이스케이프·시나리오 동작 회귀.
- 브라우저 검증은 로컬 실행입니다. CI는 Node 검사와 standalone 빌드·Artifact 업로드를 수행합니다. 실장비 운영 배포나 파트너 PC 접속 시험은 포함하지 않습니다.
