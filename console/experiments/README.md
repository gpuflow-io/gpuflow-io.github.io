# 수동 DAOS I/O 재현

`daos_io_probe.py`는 이미 구성된 시험용 DAOS 클라이언트에서 운영자가 직접 실행하는 도구다. 웹/API에서 호출하지 않는다. 기존 인증·연결 설정을 사용하며 비밀 값은 출력하지 않는다.

```bash
python3 daos_io_probe.py --pool <시험용-Pool-UUID> --system <DAOS-system-name>
```

실제로 데이터를 쓰므로 지정한 Pool이 테스트 대상인지 확인한다. Pool Ready·rebuild idle·용량 여유를 검사하고 유일한 임시 컨테이너를 만든다. 16 MiB 파일 8개를 쓰고 읽으며 SHA-256을 검사한다. 기존 컨테이너에는 쓰지 않는다. 임시 라벨·UUID를 다시 확인한 뒤 자신이 만든 컨테이너만 삭제한다. 메모리 디스크 임시 파일도 정리한다. 서비스나 네트워크 구성을 바꾸지 않는다.

출력은 JSON Lines다. phase, I/O 시작/종료, 결과·정리를 남긴다. 원본에는 실제 Pool/컨테이너 UUID가 있으므로 외부 공유 전에 식별자를 치환한다. 인증 값은 포함하지 않는다. 실패하면 `result.status=failed`와 정리 결과를 확인한다. 호스트 자체가 종료되거나 강제 종료(SIGKILL)되면 정리 코드가 실행되지 않을 수 있으므로 해당 실행의 고유 라벨·UUID를 기준으로 잔여 컨테이너를 확인한다. 다른 컨테이너를 일괄 삭제하지 않는다.

초기 공간 하한: SCM 256 MiB, NVMe 1 GiB, 로컬 임시 메모리 디스크 128 MiB. 실제 DAOS 내부 예약 용량을 보장하는 성능·가용성 기준이 아니라 이 시험의 사전 중단 기준이다. 저용량·degraded·rebuild 중에는 진행하지 않는다. I/O 명령 timeout과 파일 개수를 제한한다. 동일 Pool의 다른 활동을 막지 않으므로 원천 지표는 이 시험만의 계측이라고 볼 수 없다.
