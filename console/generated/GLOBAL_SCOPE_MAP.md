# 전역 범위·Period·Role 매핑

2026-11-10 · 목업·소스·가공·화면 연결판 · revision 2026-11-13.1 · 검토 초안. 담당·제품 주기·평가 조건은 미팅 확정.

| 항목 | 현재 지원·책임·결정 사항 |
| --- | --- |
| physical | cluster/POD/rack/node: 토폴로지 레지스트리. 현재 필터는 ① 컴퓨트 영역만 지원. ②~⑬ 전역 적용은 미연동이며 스토리지 전체 범위와 구분. |
| period | 저장 관측: captured_at 고정. API 보기: 조회 시각. 원본 Live 2s/1h·1m/12h·10m는 query_range 기간·step·recording rule·raw 보존 계약이며 UI 5초 polling과 별개. 현재 1m/10m 선택 조회 미제공. |
| logical | tenant/namespace 등록 주체: 스케줄러 연동·업무 레지스트리 제공 기관(후보). 글루시스 정규화/API, 온라인파워스 화면 필터. 원본 필드 미포함과 서버 강제 필터 미지원 상태를 구분. 이름을 추정하지 않음. |
| role | 현재 실권한은 testbed_all Bearer 범위. UI Role로 실제 사용자 권한을 바꾸지 않음. 제품 역할/tenant 강제: 온라인파워스 백엔드의 사용자 인증·화면 조합, 글루시스 API의 위임 신원·데이터 범위 검사 공동 계약 필요(미정). VM 직접 조회도 같은 범위 강제 주체 결정 필요. |
| audit | Role 전환/접근/변경의 audit.access/change 발행·actor/request_id·보존·조회 권한: 온라인파워스/글루시스 공동 미팅 결정. 원본 User→team-infer 고정은 목업 예시이며 실제 테넌트로 복제하지 않음. |
| modes | 현재 시나리오/저장 관측/API 조회 제공. Replay는 출처 라벨과 구분되는 과거 시간축 재생 기능으로 제품 제공 여부 미정. 저장 관측은 재생 아님. 시계·Pause의 의미와 Period 적용을 함께 결정. |
