# 목업 기준 · 기관 소스 → 글루시스 가공 → 온라인파워스 화면 연결

2026-11-10 · 목업·소스·가공·화면 연결판 · revision 2026-11-14.1 · 검토 초안. 담당·제품 주기·평가 조건은 미팅 확정.

목업을 요구사항 기준으로 사용합니다. 시나리오 값은 예시이며 기관의 실제 제공·제품 구현을 뜻하지 않습니다.

기관 원천 → exporter·API·이벤트 → node-agent/수집 → 글루시스 정규화·레지스트리 연결·파생 계산 → VM / 업무 API → 온라인파워스 화면

분모·상태·식별자 연결·업무 의미가 있는 집계는 글루시스 제공 책임으로 제안합니다. 온라인파워스는 합의된 결과의 조회·캐시·단위 표시·정렬·차트·오류 표시를 맡습니다. 제품 반영 위치와 일정은 미팅에서 확정합니다.

시계열: 온라인파워스 백엔드가 VM을 직접 조회하는 현재 방향을 유지합니다. 글루시스가 파생 지표·조회 규칙을 준비합니다. 목록·이벤트: 글루시스 업무 API를 조회합니다. 새 필드나 집계 API는 이 문서만으로 제공된 것이 아닙니다.

기관명은 제공 후보 또는 기존 역할에 따른 협의 대상입니다. 기관 원천 이름·필드·단위·식별키·주기·샘플·담당·제공일은 회신으로 확인해야 합니다. TTA는 검증 주체이며 exporter 개발 의무를 부여하지 않습니다.

미정 — 각 제공기관·글루시스·온라인파워스 / 화면·API 미팅에서 제공 범위·담당·기한을 확인
